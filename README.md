# 世界史ノート（授業用）

シンプルな授業用ノートアプリ（個人利用）。ローカルで実行してウェブブラウザで使います。


セットアップ:

```bash
cd /home/omoto/デスクトップ/jugyonote
npm install
npm start
# ブラウザで http://localhost:3000 を開く
```

環境変数（ジオコーディング用）:
- サーバー側で Google Geocoding API キーを使う場合、`GEOCODING_KEY` を設定してください。例:

```bash
export GEOCODING_KEY="AIza...あなたのキー..."
npm start
```
これによりクライアント側にAPIキーを埋め込まずにジオコーディングが使えます。

主な機能:
- ノート作成・編集・削除（`世紀` / `年` / `タイトル` / `タグ` / 内容）
- ノート一覧（カード表示）
- 検索：世紀・年・タイトル・タグ・本文で検索可能
- ソート：新しい順・年代順（昇順/降順）
- マークダウンプレビュー（`プレビュー切替`ボタン）
- デバウンス自動保存（入力停止後1.5秒で自動保存）
- キーボードショートカット：Ctrl/Cmd+S（保存）、Ctrl/Cmd+N（新規）
- JSONでエクスポート
- CSVでのエクスポート
- JSONファイルからのインポート
- ブラウザlocalStorageへの自動バックアップ（1分ごと）と復元

追加ツール:
- `test_smoke.sh`: APIの簡易スモークテスト（`curl` と `jq` が必要）

注意点:
- localStorageバックアップはブラウザローカルに保存されます。重要データは別途エクスポートしてください。

印刷:
- エディタの `印刷` ボタンで現在のノートを印刷できます。印刷用のスタイルを追加し、印刷時はUI要素を自動で非表示にします。

地図（マップ）機能:
- ノートに `緯度(lat)` / `経度(lng)` を入力して場所を保存できます。
- `地図で選択` を押すと地図上をクリックして座標を設定できます。
- 地図上には保存済みノートのマーカーが表示され、マーカーをクリックするとそのノートを読み込みます。

線画（ポリライン）機能:
- サイドの `線を描く` を押すと描画モードになり、地図上をクリックして経路を点で追加できます。
- `線をクリア` で現在の一時線画を消せます。
- 保存すると描画した座標（`geom`）がノートに保存され、地図上に青い線で表示されます。

注意:
- 現在の実装では描画は単純なポリラインです。面やスタイリング、編集（頂点移動）の高度な操作は今後追加できます。

AI 機能:
- `情報提供 (AI)` はノート本文から重要語句を抽出し、外部の百科事典（Wikipedia）から簡潔な説明を取得して表示します（あくまで補助的な情報提供です）。
- `要約生成 (AI)` は本文から簡易要約を作成して画面に表示します。

注意:
- 描画ツールは無効化され、既存の保存済みジオメトリ（`geom`）は引き続き地図上に表示されます。

注: 現在は手動で座標を入力するか地図クリックで選択します。住所検索（ジオコーディング）を自動化するには外部APIキーが必要です。


使い方（簡単）:
- 左側でノートを作成・編集します。右側に一覧が表示され、クリックで読み込みます。
- 上部の検索で絞り込み、ソートで表示順を変えられます。
- `プレビュー切替`でマークダウンの表示・非表示を切り替えられます。

デプロイ: このアプリは簡易なNode/Expressアプリです。HerokuやVPSで `npm start` が動く環境に配置すれば動作します。静的だけで公開したい場合は `public` 配下を静的ホスティングし、APIは別サーバーでホストしてください。
